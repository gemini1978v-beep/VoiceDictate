# Бордо · кристалл — четвёртая тема «Голосового ввода»

Примеры для темы по макету пользователя (бордовое стекло) и по сайту
[aisciencesmm.ru/#club](https://aisciencesmm.ru/#club). Код программы не менялся.

| Файл | Что в нём |
|---|---|
| `theme-bordo.css` | Тема в формате проекта: блок `:root[data-theme="bordo"]` с теми же токенами, что у трёх тем в `ui/index.html`, правила «кристалла», рубиновая запись, миниатюра `.sw-bordo` |
| `mockup.html` | Макет: настоящий интерфейс программы (`ui/index.html` в демо-режиме) с подключённой темой — главное окно (ожидание и запись) и настройки (Дополнительно, Основное) |

Как открыть макет: из папки проекта `python -m http.server 8770`, затем
`http://localhost:8770/design/bordo-crystal/mockup.html`.

## Что взято с сайта

Карточки сайта (`.crystal`) — это не просто полупрозрачность, а пять слоёв:

1. **Заливка-градиент**: `linear-gradient(135deg, rgba(255,255,255,.047), rgba(33,11,21,.54))` + `backdrop-filter: blur(18px)`.
2. **Светлая верхняя кромка**: `inset 0 1px 1px rgba(255,255,255,.4)`.
3. **Холодный отсвет по левой кромке** (преломление): `inset 1px 0 2px rgba(182,222,246,.16)`.
4. **Второй внутренний слой** (`::before`, отступ 5px): `radial-gradient(at 16% 0%, rgba(214,234,255,.04), transparent 47%)`.
5. **Блик-нить по верху** (`::after`, 2px, от 8% до 78% ширины): `linear-gradient(90deg, transparent 3%, rgba(164,217,255,.49) 17%, rgba(238,250,255,.81) 31%, rgba(184,220,255,.54) 48%, transparent 90%)`, `opacity .6`, `blur(.2px)`.

Плюс глубина снизу `0 22px 35px -18px rgba(8,1,8,.67)` и обводка `1px rgba(219,204,217,.31)`.
Шрифты сайта: заголовки — **Cormorant Garamond** (500, курсив для акцентов), интерфейс — Manrope.

### Шрифт заголовка

`--font-title: "Cormorant Garamond", "Playfair Display", Georgia, serif` — 600, 36px.
На сайте именно Cormorant Garamond; ChatGPT советовал Playfair Display — оба с кириллицей.
Программа работает без интернета, поэтому шрифт нужно положить в неё (woff2, лицензия OFL,
кириллица ~40 КБ на начертание) и подключить через `@font-face` с `data:`-адресом в `ui/index.html`.
Без этого будет Georgia — тоже антиква, но проще.

## Что поменять в программе, чтобы тема заработала

1. `ui/index.html`: вставить блоки 1–3 из `theme-bordo.css` рядом с темами; добавить четвёртую плитку
   `<button class="theme-tile" data-theme-id="bordo"><i class="sw sw-bordo"></i><span data-en="Bordeaux">Бордо</span></button>`
   и `.themes { grid-template-columns: repeat(4, 1fr); }`; в `themeId()` пропускать `'bordo'`.
2. Волна при записи берёт цвет из токена `--rec` (r,g,b); у «Бордо» — рубин `255,70,105`. Раньше JS рисовал её зелёным,
   теперь это сделано в программе.
3. `ui/files.html`: тот же блок токенов (окно «Распознать файл»).
4. `Settings.ThemeId`: добавить `"bordo"`; `WebUi.BackColor`: `bordo → RGB(42,13,23)`;
   `WebUi.LoadHtml`: ставить `data-theme="bordo"` так же, как obsidian/graphite.
5. Шрифт заголовка — см. выше.

Выбор темы сохраняется тем же способом, что и сейчас: `theme = bordo` в `settings.ini`.
