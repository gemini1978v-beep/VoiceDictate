1-е нажатие — запись, 2-е — отправка. Щёлкните в поле и нажмите новое сочетание.
Если антивирус (например, Касперский) не даёт программе микрофон, а в браузере он работает, — выберите «Через браузер»: откроется вкладка, её нужно держать открытой.
«На компьютере» — бесплатно и без интернета. OpenRouter — облачные модели: платно, с баланса OpenRouter, только за записанные секунды.
Ключ хранится в settings.ini рядом с программой.
Дешёвые сверху. Список и цены — с сайта OpenRouter. Для русской диктовки хороши Whisper Large V3 Turbo и MAI-Transcribe 2.
